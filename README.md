# Open Import OS — 美国进口成本测算（在线演示）

纯前端静态站点，计算引擎（`packages/core` 的 `calculateLandedCost` / `calculateProfit`）经 esbuild 打包为 `engine.js`，在浏览器本地运行。

- 无需后端、无需数据库、无需登录
- 全部计算在本地完成，不上传任何数据
- 确定性引擎：同样的输入永远得到同样的结果

## 计算口径
- 单件/整批费用分离，批次费用按数量精确分摊（尾差守恒）
- 未知税费不等于 0：未确认项单独列出，不混入总额
- 手动总税额与显式关税税率重叠时阻断，避免重复计税

## 免责
本工具提供基于用户输入费率的已知成本测算，不构成报关或法律意见。HTS 归类须由持牌报关人确认。
